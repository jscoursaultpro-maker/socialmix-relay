📖 README / Setup

URIs à déclarer dans le dashboard Spotify :

  • http://127.0.0.1:3000/spike/spotify.html (dev local)
  • https://api.ahouai.com/spike/spotify.html (test téléphone prod)
  • Toute URL HTTPS de preview (Render, Vercel...)

Lancement local :

  1. cd relay-server && npm start
  2. Ouvrir http://127.0.0.1:3000/spike/spotify.html

Test téléphone :

  1. Déployer sur Render (push branche)
  2. Ouvrir https://api.ahouai.com/spike/spotify.html dans Chrome Android
  3. Assurer que l'app Spotify est ouverte en arrière-plan avec un titre en pause
